# 无色 · Colorless

给新手的聊天客户端。只做五块：上下文、记忆、工具调用、主动消息、模型。
面向人机恋与刚入门的人：界面仿官方，东西少，能看懂。

## 三条底线

1. **完全本地**：消息、记忆、设置都在手机上，不装后端、不注册。
2. **一份数据一个来源**：本地库说了算，界面只显示，不猜、不合并、不去重。
3. **能删就删**：加一个功能之前先问能不能不加。

## 五块（详见 docs/五块蓝图.md）

| 块 | v0.1 | 说明 |
| --- | --- | --- |
| 上下文 | 要 | 唯一组装入口，纯函数 |
| 记忆 | 要（纯记录档） | 不配 embedding 也能用，配了就升级成向量档 |
| 模型 | 要 | 多站点 + 每个站点各自选模型 |
| 工具调用 | v0.2 | 先 10 个以内 |
| 主动消息 | v0.2 | 本地闹醒，不需要服务器 |
