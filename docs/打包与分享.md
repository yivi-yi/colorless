# 打包与分享

## 怎么出包

不用本地 Android Studio，全在云端：push 到 `main` 就自动构建，去仓库 Actions 页面下 `colorless-debug-apk`。

本地想构建也行：`gradle :app:assembleDebug`（要 JDK 17 + Android SDK）。

## 签名（还没定，发群之前必须定）

现在走的是默认 debug 签名。**问题**：云端 runner 每次都是全新的，debug keystore 每次重新生成，
签名不一致 → 群里的人装不了更新，只能先卸载（聊天记录一起没）。

发群之前二选一：

1. 仓库里放一把固定的 keystore（跟感知、小行星一样的做法）。缺点：公开仓库里等于公开，
   别人能签一个假包冒充你。粉丝群分享的场景通常能接受。
2. 放 GitHub Secrets（`KEYSTORE_BASE64` + 密码），workflow 里解码再用。安全，但以后克隆仓库的人没这把 key 就出不了能覆盖安装的包。

**定下来之后就不能换**，换了所有老用户都得卸载重装。

## 发群注意

- 版本号写在设置里，一眼能看见，群里问"我这是不是最新"能直接回答。
- 第一次装要允许"安装未知应用"，每个 ROM 位置不一样，群里给一张图省一半问题。
- 用户自带 API Key（我们不做中转），所以包里没有密钥，泄露风险低。
- 没有后端，出问题收不到日志 —— 所以 v0.1 就得有"导出日志"，不然全靠在群里问。
